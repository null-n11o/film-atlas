# 合意済みの要求

- 体験の優先順位は作品理解、作品同士のつながり、背景知識の探索。

- 監督・俳優の背景は作品と関係するものを選ぶ。短い概要から詳細へ進め、全作品で全欄を埋めることは求めない。

## 体験と画面

| 画面 | 初期版でできること |
|---|---|
| 作品一覧 | 対象作品を選ぶ。公開年と作品名で同名作を区別する |
| 作品ページ | 短い背景紹介から歴史・文化、監督・制作、俳優・役作り、考察へ進む。根拠がある欄のみ掲載する |
| 背景解説 | 説明、作品との接点、出典を読む。関連する場所・時代・別作品へ移動する |
| 地図・年表 | 背景解説と同じ内容を場所・時系列から確認する。文章の一覧からも同じ情報へ到達できる |
| 人物ページ | 作品に関係する人物の経験・発言・参加作品と出典を読む |
| サービスについて | 運営者、制作の意図、出典・訂正方針を知り、確認済みの個人noteへ進む |

初期表示はネタバレを含まない概要とする案。筋書きや結末に触れる解説は明示操作後に表示する。地図・年表・関連作品の表示にも同じ制御を適用する。リンク先の他サイトまでネタバレを防ぐとは約束しない。

初期版では会員登録、決済、投稿機能、利用者向けのリアルタイムAI生成、網羅的な作品検索を扱わない案。読める内容と探索操作を先に完成させる。作品数が少ない段階の検索・保存機能は利用状況に応じて判断する。

## 内容の制作と品質

AIによる調査・構成・下書きの補助と、人による確認を組み合わせる案。情報を公開状態へ移す基準と確認担当は仕様で定める。確認前の解説や架空の出典を、公開可能な完成データとして扱わない。

各解説と作品間の関係には出典を持たせる。出典の書誌情報、URL、参照日、どの記述を支えるかを記録する。リンクが存在するだけでは根拠確認の完了としない。歴史の説明、映画内の描写、制作者の明示的発言、編集者の比較・考察を区別する。

初期版の画像・地図素材は自作または利用条件を確認できるものに限定する案。作品ポスターや俳優写真を必須にしない。史実の位置と架空世界の位置を同じ地理座標として扱わず、年代や場所が不確かな項目はその範囲を明示する。

## 開発力と利用の評価

開発事例として示す対象は、出典を保持した内容管理、作品・歴史・人物の関係をたどる操作、画面間で一貫したネタバレ制御、スマートフォンでも読める画面とする案。

実利用では作品ページの閲覧、背景解説の閲覧、別作品への移動、再訪、個人noteへの外部リンク操作を測定候補とする。開発環境の操作を利用実績に含めず、noteへのクリックから読了・KCP認知・受注を推定しない。計測基盤、目標値、運用費の上限は実装・公開段階までに決める。
