## 修正対象と結果

正式見出しの未表示は、許可した読者にも正式名称を表示できないため、主担当がMinorからImportantへ変更した。9件を1回の修正工程で対応し、再レビューは行っていない。保留した軽微な指摘はない。

| 指摘 | 修正 | 再現検証 |
| --- | --- | --- |
| 許可の保存後に解除保存が失敗すると、古い許可が復元される | 保存失敗時に既存値を削除し、復元時も書込不能なら許可を採用しない | 単体の保存失敗、E2Eの解除失敗後のpageshow・再読込 |

| 条件付き作品の直接URLに表示許可ボタンがない | 安全な表示名から操作欄を作り、対象作品と必要な他作品の許可を操作可能にする | 条件付き作品への直接アクセスと解除 |

| 引用素材の表示クレジットと利用条件が表示されない | 引用素材のクレジット、作成者、入手元、利用条件、改変有無を本文へ反映する | 許可時の表示と解除時の除去 |
| frontmatterのJavaScriptエンジンが検証前に実行される | 先頭をラベルなしのYAML区切りに限定し、実行型エンジンを選択させない | JavaScript指定原稿を拒否し、副作用が起きないこと |
| 未完のHTMLタグが応答検証を通過する | 完全な許可タグを取り除いた後に開き山括弧が残れば拒否する | 未完タグ・イベント属性の拒否、ブラウザーで挿入・実行されないこと |

## 判断と未検証範囲

- 元の作業ツリーを保持するため、実装には専用worktreeを使った。判断が不適切なら作業場所の移動が必要になる。
- Superpowers 6.3.0の参照先が壊れていたため、利用可能な6.4.1を使った。違いが問題になれば手順記録の調整が必要になる。
- Astro previewは--ignore-lockで前景実行した。誤りがあればテストサーバーの起動に影響する。
- _contentのページディレクトリが無視されるため動的ルートへ置換し、URLは維持した。誤りがあれば追加データの生成に影響する。
- 実ブラウザーの200%ズームは未確認。200%文字拡大と640pxでの再配置を代替の証拠として区別した。ブラウザー固有のズーム問題は残り得る。
- 素材のコピーはラスター画像とtxtに限定した。別の確認済み形式を採用する場合は対応の追加が必要になる。
- 地図の操作領域はSVG上の44pxのHTMLボタンとした。密集時は重なる可能性があるため、常設の場所一覧を併用する。
- 正式見出しの指摘は重要な不具合として修正した。軽微扱いが妥当だった場合の追加負担は見出し更新と回帰検証の範囲になる。
- 実作品の正確性、出典品質、素材利用条件の法的な十分性、人による内容確認はTask 8以降に残す。実原稿の投入前に別途確認が必要になる。
- ホスト上のキャッシュ更新とX-Robots-Tagの実配信は、ホスト未選定のため未確認。公開前に旧成果物と索引対象を確認する必要がある。
- 解析、認証、支払い、外部公開は今回の対象外。必要になれば別の実装・検証が必要になる。
- 公開データの名称項目は条件付きtitleへ統一した。原稿には邦題・原題を保持するが、将来の併記には明示的な表示条件を設ける必要がある。
- frontmatterはラベルなしYAMLに限定した。JSONオブジェクトはYAMLとして受け入れる。エンジン名付き原稿を使う場合は区切りの正規化が必要になる。

Task 8は対象作品と公開年、掲載本数、人による内容確認担当の回答待ち。Task 9は最初の1作品が完成してから進める。会社側の未確認資料を読了扱いにしていない。マージ・公開・投稿・支払いは行っていない。
