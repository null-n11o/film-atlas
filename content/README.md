# 原稿の管理

JSONはentities、1記述ごとのMarkdownとfrontmatterはstatements、利用条件を確認する素材はassetsへ置く。『オデュッセイア』（2026年）の初稿をdraftとして保存している。人による内容確認と通常画面への掲載は未実施。tests/fixturesの架空データと確認者は動作検証専用であり、実原稿へ流用しない。

人が内容を確認したrevisionだけを公開対象にする。編集時はrevisionを進めて再確認する。revisionの更新忘れによる内容差分は機械的に保証できないため、確認担当がGit差分とrevisionを照合する。[制作手順](../docs/content-workflow.md)と[最初の1作品の状態](../docs/verification/first-work.md)を参照する。
